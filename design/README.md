# Meitalic — חבילת עיצוב (מסלול A)

מבנה `design/` לפי גרסה 1 של סטודיו פרץ. המנוע מרנדר הידר/פוטר/עגלה/צ'קאאוט; החבילה מספקת טוקנים, עמודי תוכן, תבניות ושדות.

- `tokens.json` — צבעים/פונטים/עיגול (Metallic Graphite).
- `pages/` — home, story, club-landing, partners-landing, journal, skin-quiz.
- `templates/` — product / catalog / category עם placeholders מהסט הרשמי.
- `fields.json` — 10 שדות מוצר לתבנית (hero_claim, benefits, ingredients, …).
- `variants.json` — בחירת וריאנטים להידר/פוטר/עגלה/הצעה/צ'קאאוט.
- `sample/products.json` — 3 מוצרי הדגמה (רשות).
- `assets/` — תמונות, וידאו, לוגו.

כל push ל-`main` = גרסה חדשה בכרטיס השוכר.
